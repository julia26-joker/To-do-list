Я выполнила задачу 1. To-Do List

Условие:
Консольное меню, создать, редактировать, удалить задачу,указывать срок выполнения, менять приоритеты,сортировать по датам, искать по атрибутам.

Реализация:

Программа  состоит из трёх файлов:

Main.java - содержит меню и запуск программы

Task.java - содержит описание класса 

TaskManager.java - содержит управление списком задач


Дополнительно реализованы функции:

отметка задачи как выполненной и  сохранение списка задач в файл tasks.txt

Программу запускаю из консоли и она  сохраняет задачи между запусками.

Поиск осуществляется по двум атрибутам - это название и описание задачи.
